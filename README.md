# millie-on-kitkat

Android 4.4 기반 전자책 단말기에서 밀리 e-ink 앱을 사용할 수 있도록 호환성을 보완하는 ReVanced 패치입니다.

> [!CAUTION]
> **원본 APK와 패치된 APK는 배포하지 않습니다.**
> 사용자는 저작권법에 따라 정당한 권한으로 원본 APK를 직접 획득하고 사용해야 합니다. 이 패치와 분석 자료를 호환 목적 이외에 사용하면 법령을 위반할 소지가 있습니다.

## 주요 변경사항

- 구형 Android 환경에서 로그인 통신을 위한 TLS 호환성 보완
- 앱 시작을 막는 업데이트 안내 생략
- 패치 후 서명 변경으로 발생하는 실행 중단 문제 보완
- 루트 권한이나 시스템 파일 변경 없이 설치 가능

## 설치 방법

### 준비물

- **Android 8 이상 휴대폰**과 [ReVanced Manager 2.6.0](https://github.com/ReVanced/revanced-manager/releases/tag/v2.6.0)
- 정당한 권한으로 획득한 **밀리 e-ink 2.1.0.0 원본 APK** ([공식 다운로드](https://apis.millie.co.kr/v1/download/apk/millie-app-2.1.0.0.apk]))
- 앱을 사용할 **Android 4.4 / ARMv7 전자책 단말기**

일반 밀리의서재 앱, 다른 버전의 e-ink 앱, 이미 패치된 APK는 지원하지 않습니다.

### 휴대폰에서 패치하기

다음 소스 주소를 복사하세요.

```text
https://raw.githubusercontent.com/hegelty/millie-on-kitkat/main/patches.json
```

1. 휴대폰에 ReVanced Manager를 설치하고, 원본 APK를 저장합니다.
2. Manager에서 **패치 번들 → 연필 아이콘(우하단) → + 패치 추가 → URL 입력 → 다음**를 누릅니다.
3. **패치 번들 URL**에 위 주소를 붙여 넣고 **추가**를 누릅니다. 다운로드가 끝나면 목록에 **Millie e-ink patches**가 나타나는지 확인합니다. **자동 업데이트**를 켜면 이후 패치 파일의 업데이트도 받을 수 있습니다.
4. **앱 → 기기 저장소에서 선택**에서 원본 APK를 선택합니다.
5. **패치 선택**에서 **Millie e-ink KitKat TLS** 하나만 선택하고 **패치**를 누릅니다. 다른 패치는 함께 선택하지 마세요.
6. 완료되면 **저장 버튼(좌하단)**으로 결과 파일을 저장합니다.

위 메뉴 이름은 Manager 2.6.0 한국어를 기준으로 합니다. 앱 언어에 따라 표시가 다를 수 있습니다. 패치 파일이 업데이트되어도 단말기에 설치된 밀리 앱이 자동으로 바뀌지는 않습니다. 새 패치를 적용하려면 원본 APK를 다시 패치한 뒤 설치하세요.

### 전자책 단말기에 설치하기

1. 휴대폰에서 저장한 APK를 USB 연결 등으로 전자책 단말기에 옮깁니다.
2. 기존 밀리 앱이 설치돼 있다면 필요한 기록이 계정에 동기화됐는지 확인합니다. 서명이 다른 앱은 덮어쓸 수 없으므로 기존 앱을 삭제해야 할 수 있습니다. **앱을 삭제하면 다운로드한 책과 기기에만 저장된 앱 데이터도 지워집니다.**
3. 단말기에서 APK 파일을 열어 설치합니다. 설치가 차단되면 단말기의 설정에서 해당 파일을 설치할 수 있도록 허용합니다.
4. 앱을 실행하고 본인의 밀리 계정으로 로그인합니다. 서비스 이용에 필요한 구독과 도서 이용 권한은 별도로 갖추어야 합니다.

**처음 실행할 때 “정상적인 경로로 밀리를 설치해 달라”는 취지의 경고가 한 번 표시될 수 있습니다. 이는 알려진 정상적인 현상이므로 경고를 닫고 진행하면 됩니다.** 경고가 반복되거나 앱이 종료되는 경우는 별도로 확인해야 합니다.

이후에도 같은 서명으로 패치하려면 Manager의 서명 키를 보관하세요.

이 저장소에서는 [저작권법 제101조의4 제1항](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=04&joNo=0101&lsiSeq=283335&urlMode=lsScJoRltInfoR)과 [같은 법 제104조의2 제1항 제6호](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=02&joNo=0104&lsiSeq=283335&urlMode=lsScJoRltInfoR)에 따라, 정당한 이용자가 구형 Android 환경에서 프로그램 간 호환성을 확보할 수 있도록 필요한 범위의 프로그램코드역분석과 수정을 진행했습니다.

해당 조항의 적용에는 정당한 이용 권한, 호환 정보 획득의 필요성, 필요한 범위로의 제한 등 법률상 요건이 따릅니다. 호환 목적이라는 설명만으로 모든 이용이나 배포의 적법성이 보장되지는 않습니다.

- **이 프로젝트는 있는 그대로(AS IS) 제공됩니다.** 개발자와 기여자는 법령이 허용하는 범위에서 정상 동작, 특정 목적에 대한 적합성, 보안성, 서비스의 지속 이용 및 제3자의 권리 비침해를 보증하지 않습니다.
- **사용자는 원본 APK의 취득, 패치, 설치, 이용 및 배포 등 자신의 행위에 따른 모든 민·형사상 책임을 부담합니다.** 개발자와 기여자는 법령이 허용하는 범위에서 프로젝트 사용으로 발생한 데이터 손실, 기기 오작동, 계정 제한 및 그 밖의 손해에 책임을 지지 않습니다. 법률상 배제하거나 제한할 수 없는 책임은 이 면책조항의 적용 대상에서 제외됩니다.
- 원본 앱과 도서 등 콘텐츠의 권리는 각 권리자에게 있습니다. 이 프로젝트는 해당 권리에 대한 이용 허락을 부여하지 않습니다. 원본·수정 APK나 콘텐츠를 권한 없이 공유하거나 재배포하지 마세요.
- 패치와 분석 자료는 호환 목적에 필요한 범위에서만 사용해야 합니다. 무단 복제, 구독·접근 권한 우회 등 호환 목적 이외의 이용은 법령 위반 소지가 있습니다.
- 밀리의서재나 ReVanced가 제작·승인한 프로젝트가 아니며, 공식 지원을 제공하지 않습니다.
