## 확인한 범위

| 항목 | 결과 |
|---|---|
| 번들 빌드 및 코어 검사 | JVM·Android용 번들 빌드와 입력 검사를 통과했습니다. |
| Manager 2.6.0 | Android 9 / x86_64 에뮬레이터에서 가져오기·패치·서명·내보내기를 확인했습니다. |
| Manager 최종 결과 | 재생성한 결과가 ZIP CRC와 v1/v2/v3 서명 검증을 통과했습니다. |
| CLI와 Manager 결과 비교 | 서명 관련 항목을 제외한 1,113개 ZIP 항목의 내용이 같았습니다. |

| 기존 방식의 APK | 사용자가 실기기에서 실제 로그인·독서가 정상 동작하며, 최초 실행 시 설치 경로 경고가 한 번 나타난다고 보고했습니다. |

기존 방식의 APK에 대한 실기기 확인은 ReVanced로 생성한 APK의 실기기 검증을 대신하지 않습니다. ReVanced 결과의 실제 계정 로그인·서재·다운로드·독서와 휴대폰에서의 Manager 실행은 아직 확인하지 않았습니다. Manager 결과는 ARMv7 에뮬레이터에 별도로 설치하지 않았으며, 실행한 CLI 결과와 앱 내용이 같음을 확인했습니다.

## 알려진 문제

Manager의 첫 생성 결과에서 수정 대상이 아닌 PDF 라이브러리의 압축 데이터가 손상돼 ZIP CRC 검사가 실패했습니다. 같은 원본과 같은 번들로 다시 생성한 결과는 CRC·파일 내용·서명 검증을 모두 통과했지만, 첫 손상의 원인은 확인되지 않았습니다.

따라서 아직 모든 기기에서 안정성을 확인한 버전은 아닙니다. 패치 결과에 설치 오류나 실행 이상이 있으면 해당 파일을 계속 사용하지 말고, 원본 버전과 패치 선택을 확인한 뒤 다시 생성하세요. 개발자는 [검증 도구](README.md)로 출력 파일을 확인할 수 있습니다. 서명 검증만으로 파일 내용의 정상 여부를 판단할 수는 없습니다.

다른 앱 버전·ABI, 다른 패치와의 조합, 후속 Manager 버전은 검증하지 않았습니다.
